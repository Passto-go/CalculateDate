# 纪念日吖

一个记日子的小网页。

本来只是想有个地方能看着日子一天天往后数，后来就慢慢做成了现在这样。页面上有几张卡片，每张记一个日子，秒数一直跳。挺简单的，但自己看着挺高兴。

## 想改日子的话

所有要改的东西都在 `data.json` 里，一个卡片一条。想加一个，就往 `[...]` 里再塞一条；想改名字、改日期、改底下的说明，直接改对应的字就行。存好提交，网页刷新一下就是新的。

几个字段说一下：

- `title`：卡片上的大标题
- `date`：日期，写 `2026-05-20` 这样
- `dateLabel`：日期底下那行小字，想写什么写什么
- `icon`：图标，用 FontAwesome 的名字，比如 `fa-heart`
- `theme`：配色，可选 `game-theme`、`dungeon-theme`、`birthday-theme`、`birthday2-theme`
- `calendar`：农历日期加这一行，写 `"lunar"`，程序会自动换算成公历，页面上还是显示农历
- `placeholder`：日子还没定的，写 `true`，卡片会显示"待定"不计时；等日期有了把这一行删掉、填上 `date` 就开始数了
